# 📊 Madhav Ecommerce Sales Dashboard (Power BI)

## 📌 Project Overview
Interactive Power BI Sales Dashboard built using an e-commerce dataset.
This project demonstrates the complete BI workflow—data preparation in Power Query, a data model, and visual analytics—to support data-driven decision making.

## ✅ Key Highlights
- Prepared the raw data in Power Query: promoted headers, set data types, and converted the day-month-year order dates correctly using the English (India) locale
- KPI cards for Total Amount, Profit, Quantity and AOV, plus one DAX calculated column (AOV = Amount ÷ Quantity)
- Insights on sales by state, category, payment mode and top customers, and profit by month and sub-category
- Interactive Quarter and State slicers that filter the whole page

## 🚀 How to Use
1. Download the .pbix file from this repository.
2. Open using Power BI Desktop (free tool).
3. Explore the dashboard using the Quarter and State filters.
   If Power BI cannot find the data, go to Home → Transform data → Data source settings, and point Orders.csv and Details.csv to your downloaded copies.

⭐ Clean, insight-driven dashboard designed for business decision making.
